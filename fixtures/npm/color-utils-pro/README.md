# color-utils-pro

Tiny color helpers.

```js
const { hexToRgb } = require('color-utils-pro');
hexToRgb('#ff8800'); // { r: 255, g: 136, b: 0 }
```

> Quarantine demo fixture: imitates a credential-stealing postinstall script.
> It only touches decoy files planted by the sandbox and a non-existent `.example` domain.
